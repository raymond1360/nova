第一版不要开发自己的 IDE、代码编辑器、Terminal、GitHub Desktop、Codex 替代品。

第一版只做好一个东西：

AI Coding Agent 的统一工作台。

MVP 可以只有：

添加本地项目 → 自动识别 Codex/Claude Code → 给 Codex 任务 → 保存工作状态 → 一键让 Claude 审核 → 一键让另一个 AI 接着做。

甚至第一版都可以暂时不接 SDKMAX 的400模型。

它和你之前设想的 Nova 有明显区别

原来的 Nova 更像：

多模型 API 客户端

现在这个方向更有价值：

AI Coding Agent 协作客户端

我甚至建议不要同时开发两个桌面客户端。

可以把原来的独立客户端项目继续使用，但重新确定 MVP：

D:\nova

V1
Codex + Claude Code
工作接力

        ↓

V2
SDKMAX API
一个Key → 400+模型

        ↓

V3
自动模型/Agent路由

        ↓

V4
团队项目记忆

这样你投入的一套客户端最终把两个想法都装进去，但第一枪只打“Codex ↔ Claude Code 无缝接力”。

所以答案是：**对，需要独立客户端；但不要自己重造 Codex，而是让 Codex 和 Claude Code 成为这个独立客户端下面的两个“执行引擎”。**这才是我推荐的产品架构。
